# 測試說明：批量會員影片/系列開通功能 V2

## 測試目標
驗證 `/bulk_create_accounts_v2` 路由與相關功能，確保可正確上傳 CSV 檔案並批量處理會員影片/系列開通。

## 測試項目

### 1. 頁面功能測試
- 進入管理後台，點擊導航中的「批量會員影片/系列開通 V2」連結，應正確進入 `admin_bulk_create_accounts_v2.html` 頁面。
- 頁面應顯示上傳 CSV 檔案的表單，並有下載範例檔案的連結。

### 2. CSV 上傳測試
- 上傳格式正確的 `bulk_create_accounts_v2_sample.csv`，應顯示處理成功訊息，並正確批量開通對應會員的影片/系列。
- 上傳格式正確但內容有重複或異常資料的 CSV，應顯示錯誤訊息，並標示失敗的行數與原因。
- 上傳格式錯誤（如缺少必要欄位）的 CSV，應顯示格式錯誤提示。

### 3. 資料庫驗證
- 上傳後，檢查 `UserRepository`、`VideoRepository`、`BatchAccountLogRepository` 是否有正確寫入對應資料。
- 驗證批量開通後，會員可於前台正常看到新開通的影片/系列。

### 4. 權限與安全性
- 非管理員帳號嘗試進入 `/bulk_create_accounts_v2`，應被拒絕存取。
- 上傳過大或惡意檔案時，系統應有適當的錯誤處理與提示。

### 5. 邊界與異常測試
- 上傳空檔案、僅標題無資料、或超過預期欄位數的檔案，應有明確錯誤提示。
- 連續多次上傳，系統應能正確處理並避免重複開通。

## 測試步驟範例
1. 以管理員身份登入後台。
2. 進入「批量會員影片/系列開通 V2」頁面。
3. 下載範例 CSV，填入測試資料。
4. 上傳檔案，觀察回饋訊息。
5. 於會員端驗證影片/系列是否正確開通。
6. 檢查資料庫紀錄。
7. 測試異常情境（如格式錯誤、權限不足等）。

## 預期結果
- 正常上傳時，所有指定會員的影片/系列皆正確開通。
- 異常情境下，系統能給予明確錯誤提示且不影響其他資料。
- 權限控管正確，非管理員無法操作。
