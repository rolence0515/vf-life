# 如何取得 Vimeo 的嵌入網址

在嵌入 Vimeo 影片到您的網站時，請務必使用嵌入網址，而非分享網址。以下是兩者的區別以及如何正確取得嵌入網址的步驟。

## 分享網址與嵌入網址的區別

1. **分享網址**
   - 分享網址通常是用於將影片連結分享給他人。
   - 點擊分享網址後，使用者會被導向 Vimeo 官方網站觀看影片。
   - 分享網址的格式通常如下：
     ```
     https://vimeo.com/123456789
     ```

2. **嵌入網址**
   - 嵌入網址是用於將影片直接嵌入到您的網站中，讓使用者可以在您的網站上直接觀看影片。
   - 嵌入網址的格式通常如下：
     ```
     https://player.vimeo.com/video/123456789
     ```

## 如何取得嵌入網址

1. 登入您的 Vimeo 帳戶，並找到您想要嵌入的影片。
2. 點擊影片右下角的「分享」按鈕（Share）。
3. 在彈出的分享選項中，找到「嵌入代碼」（Embed Code）。
4. 嵌入代碼中會包含嵌入網址，格式如下：
   ```html
   <iframe src="https://player.vimeo.com/video/123456789" width="640" height="360" frameborder="0" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen></iframe>
   ```
5. 從嵌入代碼中提取 `src` 屬性的值，即為嵌入網址：
   ```
   https://player.vimeo.com/video/123456789
   ```

## 分享網址無法取得嵌入網址

需要注意的是，分享網址無法直接轉換為嵌入網址。這是因為分享網址僅用於將使用者導向 Vimeo 官方網站，而嵌入網址則是專門用於嵌入影片的特殊格式。

如果您僅有分享網址，請按照以下步驟取得嵌入網址：

1. 登入您的 Vimeo 帳戶。
2. 找到您擁有的影片，並點擊「分享」按鈕（Share）。
3. 在分享選項中，找到「嵌入代碼」（Embed Code）。
4. 從嵌入代碼中提取 `src` 屬性的值，即為嵌入網址。

如果影片的嵌入功能被關閉，您將無法取得嵌入網址，請聯繫影片擁有者以確認隱私設定是否允許嵌入。

## 注意事項

- 嵌入網址可以直接用於 `<iframe>` 標籤中，讓影片嵌入到您的網站。
- 請勿使用分享網址，因為分享網址會將使用者導向 Vimeo 官方網站，而非在您的網站內嵌播放。
- 如果需要自動播放或其他功能，可以在嵌入網址後添加參數，例如：
  ```
  https://player.vimeo.com/video/123456789?autoplay=1
  ```

透過正確使用嵌入網址，您可以確保使用者在您的網站上獲得最佳的觀看體驗。
