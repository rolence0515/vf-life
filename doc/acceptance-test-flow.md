# 驗收測試流程說明（簡易版）

本專案登入與密碼相關功能共四個頁面，請依下列步驟進行驗收測試：

## 1. 登入頁面（login）
- 開啟 `/login` 頁面。
- 輸入正確/錯誤的帳號密碼，確認提示訊息正確顯示。
- 測試「記住此裝置」勾選與否的行為。
- 驗證 hCaptcha 驗證碼必須通過才能送出。
- 點擊「忘記密碼？」可正確跳轉到忘記密碼頁。

## 2. 忘記密碼頁面（forgot_password）
- 開啟 `/forgot-password` 頁面。
- 輸入已註冊/未註冊的 Email，確認提示訊息正確顯示。
- 驗證 hCaptcha 驗證碼必須通過才能送出。
- 點擊「返回登入」可正確跳轉回登入頁。
- 點擊送出後，確認有收到重設密碼信件（檢查收件匣或垃圾郵件）。

## 3. 重設密碼頁面（reset_password）
- 透過忘記密碼流程取得重設密碼連結，開啟該頁面。
- 輸入新密碼與確認密碼，測試一致/不一致時的提示。
- 成功重設後，確認可跳轉回登入頁。

## 4. 修改密碼頁面（change_password）
- 登入後進入修改密碼頁。
- 輸入舊密碼、新密碼、確認新密碼，測試正確/錯誤情境。
- 成功修改後，確認提示訊息正確。
- 點擊「返回登入」可正確跳轉回登入頁。

# 訪客外站驗收測試流程（簡易版）

## 1. 首頁（index）
- 開啟 `/` 首頁，確認頁面可正常載入，內容顯示正確。
- 測試「登入觀看影片」按鈕，未登入時應導向登入頁。
- 測試「查看活動詳情」按鈕可正確跳轉至活動主題區塊。
- 檢查六大主題區塊內容、購票連結正確。
- 檢查回放說明、聯票福利等資訊區塊內容正確。

## 2. 404 頁面（404）
- 隨意輸入不存在的網址（如 `/notfound`），確認顯示 404 頁面。
- 檢查 404 頁面文案、返回首頁按鈕可正常運作。

## 3. 活動資訊頁/其他靜態頁
- 檢查所有外部連結（如購票、社群、活動說明）可正確開啟。
- 檢查頁面排版、圖片、文案無誤。

## 4. FAQ 頁面（faqs）
- 開啟 `/faqs` 頁面，確認頁面可正常載入，FAQ 問答內容顯示正確。
- 檢查每個問題可展開/收合，答案內容正確。
- 檢查 FAQ 連結在主選單可正常點擊並導向本頁。
- 檢查頁面排版、樣式、圖示（如打勾）顯示正常。
- 檢查所有外部連結（如 Facebook、購票）可正確開啟。

- 測試切換系列時，loading 動畫顯示正確，影片資料正確更新。
- 測試登出功能，點擊「登出」可正確登出並導回登入頁。
