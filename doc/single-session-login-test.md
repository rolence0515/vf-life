# 單一使用者登入（Single Session Login）測試流程說明

本系統已實作「單一使用者登入」機制，確保同一帳號同時僅能在一個瀏覽器或裝置登入。以下為測試流程說明：

---

## 測試前準備
- 確認資料庫 user 表已新增 `session_token` 欄位。
- 確認後端程式已更新為新版單一登入邏輯。
- 準備兩個不同的瀏覽器（例如 Chrome、Firefox），或一個電腦、一支手機。

---

## 測試步驟

### 1. 首次登入
1. 在【瀏覽器A】開啟登入頁面，輸入帳號密碼登入。
2. 登入成功後，進入會員專區，確認可正常瀏覽。

### 2. 另一端登入
1. 在【瀏覽器B】或另一裝置，開啟同一個帳號的登入頁面。
2. 輸入相同帳號密碼登入。
3. 登入成功後，進入會員專區，確認可正常瀏覽。

### 3. 驗證舊端被踢出
1. 回到【瀏覽器A】，嘗試瀏覽會員專區或重新整理頁面。
2. 頁面應自動跳轉至登入頁，並顯示「您的帳號已在其他裝置登入，請重新登入」等提示。

### 4. 反向驗證
1. 在【瀏覽器A】重新登入。
2. 回到【瀏覽器B】，再次操作會員專區，應同樣被踢出並要求重新登入。

---

## 注意事項
- 不同瀏覽器、不同裝置皆適用此驗證。
- 若同一瀏覽器開多個分頁，僅有一組 session，不會互踢。
- 若 session 過期或手動登出，需重新登入。

---

## 常見問題
- 若登入後未被踢出，請確認資料庫 session_token 欄位有正確更新，且程式有正確比對。
- 若有快取問題，請清除瀏覽器快取後再測試。

---

如有問題請聯絡開發人員。
